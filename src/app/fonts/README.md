# Font assets

The app self-hosts these Google Fonts so it does not depend on a third-party font request at runtime:

- Hurricane Regular 400
- Geist Mono Regular 400
- Geist Mono Medium 500
- Funnel Display Variable 300–800
- Instrument Serif Regular 400
- Manrope Variable 200–800

These families are distributed through Google Fonts under the [SIL Open Font License 1.1](https://openfontlicense.org/).
